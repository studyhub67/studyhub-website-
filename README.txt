STUDYHUB WEBSITE — QUICK START

This is a mobile-friendly educational website with a modern blue-and-white design.

FILES
- index.html: website content
- styles.css: design and mobile layout
- script.js: mobile navigation and footer year
- notes/: put your PDF notes in this folder

ADD YOUR PDF NOTES
Put your PDF files inside the notes folder and name them exactly:
- civil-engineering.pdf
- mathematics.pdf
- physics.pdf
- english.pdf

The download links are already connected to those filenames. If you use different names, edit the matching href in index.html.

PUBLISH FREE WITH GITHUB PAGES
1. Extract StudyHub-website.zip.
2. Open your GitHub repository (create a public repository named studyhub-website if needed).
3. Upload the CONTENTS of the StudyHub folder to the repository root. Do not upload only the ZIP file.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes. Your site address will be:
   https://YOUR-USERNAME.github.io/studyhub-website/

You can do these steps from a mobile browser. Replace YOUR-USERNAME with your GitHub username.

NOTE
The PDF links are placeholders until you add your own PDF files. No student login or payment system is included.
